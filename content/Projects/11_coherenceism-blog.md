## Coherenceism.blog
**Personal Project:** ***2024–Present***

**Overview**
A philosophical content platform built on Ghost CMS, publishing daily field observations that apply coherentist thinking to current events, AI emergence, systems design, and culture. Content is produced through CORA's multi-agent pipeline — AI agents research, draft, edit, fact-check, and publish while I provide editorial direction and philosophical intent. The site also hosts the "Chronicles of Coherence" book series and serves as the written home of the Coherenceism ecosystem.

**Key Contributions**
- Designed and automated a daily field observation pipeline: source harvesting → research → drafting → editing → fact-checking → Ghost publishing → notification — running autonomously via scheduled agent heartbeats.
- Built custom Ghost theme customizations including a five-river content taxonomy (Agency, Awakening-Alignment, History-Systems, Human-AI, Rest-Rhythm) with dedicated navigation, tagging, and visual identity.
- Created publishing automation scripts for Ghost's Admin API, handling lexical content format, image management, and metadata — learning through hard-won debugging that API semantics (source format, lexical JSON structure) determine output fidelity.
- Produced 100+ field observations and multiple long-form chronicles, establishing a consistent publishing cadence with minimal manual intervention.

**Technical Stack**
- Ghost CMS (self-hosted on Docker), Caddy reverse proxy, custom CSS theming
- Node.js publishing scripts using Ghost Admin API
- CORA agent pipeline (5 river-specialist writers, editors, fact-checkers, copy editors)
- Automated scheduling via macOS launchd

**Impact**
- Established a sustainable content operation where AI agents handle production while preserving authentic philosophical voice and editorial standards.
- Demonstrated that a single person can operate a full editorial pipeline — research through publication — by serving as producer rather than writer.
