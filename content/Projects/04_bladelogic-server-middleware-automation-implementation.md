## BladeLogic Server & Middleware Automation Implementation
**Berkley Technology Serivces:** ***2010-2011***

**Overview**

Brought onto the WebSphere administration team specifically to help implement **BladeLogic Server Automate and Middleware Automation** tools, I partnered with the Release Management team to design and roll out automation for enterprise application releases. This project spanned both **WebSphere J2EE environments** and **.NET platforms**, aiming to replace error-prone manual processes with auditable, protocol-driven automation.

**Key Contributions**

- **Infrastructure & Access Setup**
    - Configured servers and environments required for BladeLogic deployment.
    - Modified permissions and access controls to support automation workflows securely.
- **Scripting & Job Automation**
    - Developed **NSH scripts** to automate routine release tasks, reducing manual effort across both WebSphere and .NET deployments.
    - Built reusable scripts and job templates for consistent release orchestration.
- **Middleware Automation Integration**
    - Applied middleware automation to WebSphere environments, ensuring releases were **auditable, compliant, and repeatable**.
    - Standardized environment provisioning and management across tiers.
- **Staff Enablement**
    - Conducted hands-on training sessions with release and operations staff to ensure effective adoption of BladeLogic tools.
    - Authored process documentation to support long-term maintainability.

**Outcome / Impact**

- Significantly reduced manual errors in release processes through automation.
- Improved **audit readiness and compliance**, ensuring releases followed consistent protocols.
- Enabled faster, more reliable deployments across enterprise applications.
- Established a foundation for future DevOps-style automation efforts within the organization.

**Reflections**

This project was a turning point in my career — where I first saw the power of **automation at enterprise scale**. It bridged my configuration management background with middleware expertise, and foreshadowed my later shift into DevOps engineering.
