## System Administration

I’ve spent years managing application environments, tuning middleware, and automating deployments across Windows and UNIX stacks. This operational experience helps me choose and configure tools with a clear understanding of how they will be supported, recovered, and used by the next person.

### Key Areas
- **WebSphere ND (v5.1 – 8.0)**: Maintained and upgraded environments across 4-tier architectures (dev, integration, test, prod). Supported vendor and custom applications.
- **BladeLogic Server & Middleware Automation**: Designed XML templates and NSH scripts for JVM configs, application deployments, and mid-tier distribution.
- **Windows & UNIX Environments**: Worked fluently across both platforms. Coordinated deployments, handled server profiles, and participated in system hardening and troubleshooting.
- **Middleware Operations**: Managed JVMs, application servers, and service dependencies across teams. Developed repeatable, scalable configuration systems.

### Notable Contributions
- Co-developed a hands-off deployment model using XML and automation for repeatable app rollout across multiple environments.
- Authored documentation for BladeLogic tools and system procedures to reduce knowledge silos.

### Perspective
I treat system administration as the substrate beneath everything else—often invisible when done right. My approach is lean and focused: make it stable, make it repeatable, make it quiet.
