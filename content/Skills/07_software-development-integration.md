## Software Development & Integration

While I’ve never identified as a pure software engineer, I’ve built a solid track record writing functional, purposeful code—especially when it connects systems, automates workflows, or reduces repetitive work. My development background is integration-heavy, always aimed at solving practical problems.

### Areas of Focus
- **System Integration**: Designed and supported communication between core platforms—like the Genesys policy system and the Agency Profile System (APS)—using PUB/SUB messaging via IBM Message Broker.
- **Plugin Development**: Built custom software plugins to connect Jira and Bamboo with ServiceNow, streamlining workflow orchestration and data handoffs.
- **Scripting for Deployment & Automation**: Authored scripts in Bash, NSH, XML, and occasionally Python to manage job orchestration, config templating, and automated deployments.
- **Agile Collaboration**: Worked within Agile teams, contributing to code reviews, maintaining documentation, and writing unit-tested enhancements.

### Notable Highlights
- Recognized as a subject matter expert on Genesys-APS integration at Berkley.
- Contributed multiple internal tools that reduced manual intervention during release cycles.

### Philosophy
I write code for a reason. I’m not here to build frameworks or chase bleeding-edge tech. I’m here to automate the boring stuff, connect the isolated stuff, and make the important stuff just work.
