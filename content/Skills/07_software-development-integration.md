## Practical Tooling & Integration

I work as a toolsmith: I understand a practical problem, choose the tools that fit, and connect the pieces into something people can use. My experience combines platform configuration, APIs, scripting, and workflow design, with code serving a clear operational purpose.

### Areas of Focus
- **System Integration**: Designed and supported communication between core platforms—like the Genesys policy system and the Agency Profile System (APS)—using PUB/SUB messaging via IBM Message Broker.
- **Connecting Enterprise Tools**: Built custom plugins to connect Jira and Bamboo with ServiceNow, bringing change requests, release workflows, and data handoffs together.
- **Scripting for Deployment & Automation**: Authored scripts in Bash, NSH, XML, and occasionally Python to manage job orchestration, config templating, and automated deployments.
- **Agile Collaboration**: Worked within Agile teams, contributing to code reviews, maintaining documentation, and writing unit-tested enhancements.
- **AI-Assisted Toolmaking**: Applied AI assistance in enterprise evaluations and prototypes, alongside scoped permissions, human review, evidence checks, and documented limits.

### Notable Highlights
- Recognized as a subject matter expert on Genesys-APS integration at Berkley.
- Contributed multiple internal tools that reduced manual intervention during release cycles.

### Philosophy
My strength is understanding how the pieces need to work together and what the people using them need. I use configuration, scripts, integrations, and AI assistance to turn that understanding into working tools. A useful result includes a way to verify it, documentation someone can follow, and a clear path when something goes wrong.
