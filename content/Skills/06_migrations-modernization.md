## Migrations & Modernization

I've been hands-on in several large-scale modernization efforts—moving legacy tools and platforms into more scalable, supportable, and coherent systems. These aren’t flashy projects, but they’re essential: less tech debt, fewer workarounds, and better long-term outcomes.

### Key Projects
- **Atlassian Server → Data Center**: Led the migration of Jira, Confluence, Bitbucket, and Crowd to high-availability Data Center environments, minimizing downtime and aligning with scaling needs.
- **Subversion → Bitbucket**: Guided a full source control migration for a major client, moving legacy code into Git workflows with improved access control and visibility.
- **Automate Desktop → Automate Plus Server**: Planned and executed the transition at Grinnell Mutual, upgrading from siloed desktop automation to a centralized, enterprise-ready platform.

### Approach
- Plan migrations like you’re planning for failure—then make it seamless.
- Collaborate with stakeholders early, document decisions, and test assumptions.
- Build fallbacks and minimize guesswork for the teams inheriting the new system.

### Tools Involved
- Atlassian Cloud Migration tools & training (ACP badge earned)
- Bitbucket / Git
- HelpSystems Automate Plus
- Custom scripting for data and config transformation
